FAQ

Common questions

Do I need to know Terraform?

No. Weboide generates the Terraform for you from simple forms. You can still view and download the code at any time.

Which cloud providers are supported?

AWS is supported today, including EC2, VPC, S3, IAM and networking resources.

Can I work with my team?

Yes. Invite teammates to a project by email and collaborate on the same infrastructure.

How are compliance checks done?

Each resource is evaluated against a set of compliance rules. You can see its status and export a report.
